## Состояние

**Вся дизайн-пачка В ПРОДЕ** (#155 + #156, проверено ассетами на hiredrop.io):
- Flow-рейка на lg+ (лого сверху, Dashboard/History/Platforms + Settings/Extension внизу), мобилка на пилюлях;
- день: белый фон, актив = плитка `--accent-light` + чёрный текст; **день v2** = глубина, не вайрфрейм:
  волосяные рамки rgba(26,26,34,.18), тень-подъём #149 на карточках, вторичный текст ПЛОТНЫЙ графит
  #3A3A46 (альфа-серые text2 запрещены, floored скоупом);
- ночь: чёрное стекло (`.dark .bg-surface` rgba(8,8,15,.6), surface2, `.hd-glass`), thead/меню почти
  непрозрачные, счётчики вкладок белые (`.jt-count`); фон страницы = СВОЯ картинка `bg/ground-night.jpg`
  (веер остался только в карточках Auto/Tap);
- рамка Live Activity: своя СГЕНЕРИРОВАННАЯ fluid-пара `bg/well-{day,night}.jpg` (день крем→оранж→малина,
  ночь шоколад+золото; один кадр, генератор `brand-visuals/fluid-hero.py`); картинка заливает весь контур карточки.

**НЕ смержено**: `design/popup-day` (репо jobflow) — попап расширения день: белый, чёрные кнопки,
ночной веер в Live process, цифры-микс. Ждёт «ок» → мерж в main jobflow → `scripts/sync-ext.sh` → OFF/ON.
