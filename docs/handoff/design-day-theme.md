## Грабли (стоили часов — не наступать)

1. **`@theme inline` замораживает `--color-*`**: объявлены на `:root` как `var(--accent)` и
   резолвятся ТАМ — скоуп-оверрайд `--accent` их не меняет. Утилиты Tailwind работают (inline
   подставляет `var(--accent)` в класс), рукописные `var(--color-accent)` — нет. Лечение:
   скоуп перевыводит `--color-*` на себе (уже в проде, #153).
2. **Фиолет был захардкожен в `.hd-glass`** (фон/кромка/тени в самом классе) — токены его
   не брали. Аналогично `group-hover:bg-accent` компилируется в класс, который оверрайд
   `.bg-accent` не матчит.
3. **CSS-переменные не ходят между соседями** — `--halo` на карточке не виден гало-соседу.
4. **dev-сервер молча не подхватывает правки globals.css** — лечение: kill + `rm -rf .next` + рестарт.
5. **Превью дашборда**: Vercel Preview = 500 (нет env), поэтому локально: worktree + свой
   `npm ci` (Turbopack не ест symlink node_modules) + порт 3777; **логин** — перенести
   свежие `sb-*` куки из вкладки hiredrop.io на localhost (протухшие не работают — refresh
   token одноразовый). Файлы с куками после — УДАЛЯТЬ.
6. **Работать ТОЛЬКО в worktree** — правки в общем чекауте одна сессия уже прочла как main.
7. Каждую правку цвета проверять живой пробой `getComputedStyle` через AppleScript-JS в
   своём окне Chrome — глазам «не изменилось» верить только после неё.

## Открытые дизайн-хвосты (по приоритету Игоря)

1. Раскладка кнопок по его скринам (ЖДЁТ СКРИНОВ) + мерж `design/white-ground-fan-cards`.
2. Tap-карточка колоды: полосы/веер на задник — нужен рефакторинг обёртки (контент под маску).

## Вкус Игоря (проверено итерациями)

Референс — Apple: минимализм ≠ бедность; «различать и наводить чистоту в деталях». Кнопки:
максимально светлые, белый градиент, золото «совсем чуть-чуть», текст ЧЁРНЫЙ (золотой текст
на золоте — «два золота спорят»). Полупрозрачность — в альфе фона + blur, никогда в opacity.
Свечение = свет, не заливка. Пустое зарезервированное место — вырезать. Показывать разницу —
только «было/стало» в реальных пропорциях, с линейками; смотреть любит живьём (прод или localhost).
