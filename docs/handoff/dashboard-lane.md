## Состояние

- **Мёртвый мост виден** (#145/#150): после релоада ext осиротевший ping.js продолжает
  отвечать PONG (эта ветка не трогает chrome.*), поэтому гейт установки «видел» расширение,
  а Start молча не долетал. Детектор (`lib/extension-bridge.ts`) слушает СУЩЕСТВУЮЩИЙ пульс

  тишина 3 промаха → ~25-30с. Правило #127: тишине верим только после ≥1 ответа — оно же
  grace period, поэтому телефон/Safari без баннера. Баннер в DashboardLayout (виден везде),
  стили = общая конвенция `bg-yellow/10`+`text-yellow`+`bg-accent`, своих цветов НЕТ.
- **Пауза различает капчу и стену согласия** (#146): `captchaWaiting.kind` ("terms"|"captcha",
  undefined=captcha для старых ext), `action` = готовая фраза с кнопкой. CTA гаснет при
  bridgeLost (протухший снимок ≠ состояние).
- **Одобренные свайпы видны** (#148): баннер «N approved swipes waiting — Auto won't apply
  them» на главной, из `/campaign/status.approved_waiting`; молчит ТОЛЬКО при submit_mode=tap.
  Сверено с продом: 4 approved у 99d0d45b…, ни одна не подана, юзер увидит.

  паузит всю кампанию; handBackJob = «доделай эту руками»); покрытие reason'ов 5/5 (#147).
- Бэкенд-гейт таста: после 40 бесплатных Interview Kit требует подписки (jobflow #188,
