# dashboard-lane — экран кампании, главная, History, мост с расширением

Обновлено: 2026-10-06 · ветка: main (всё смержено, web #284)

## Состояние

**Док внизу дашборда — плоская плашка, дуга внутри (web #284, 10-06).** `TapProgressDock`,
форма по умолчанию `bar`: дуга слева в самой плашке, цифра внутри дуги, подпись под концами
дуги («today» / «of 30 today» / «of 7»). Два состояния одного дока: пачка свайпов («Applying
the jobs you swiped», Stop / Deck) главнее счётчика живого Auto-прогона `LiveRunDock`
(«Applying for you — live», чипы платформ = легенда рейки по нижнему краю, Stop / History).
На телефоне (≤640px) кнопки уходят второй строкой. Обе темы.
Почему не купол: `dome` резервировал под кругом колонку 120px и высоту 76px — текст висел
справа, снизу пусто (Игорь 10-06: «не нравится»). `dome`/`arch` остались опцией, не дефолт.

**History — поверхность доказательства.** Строка раскрывается в запись о подаче (вакансия,
PDF, письмо, тейлор-резюме) чипами `.hd-chip`. Статус ставит сам юзер: чип = меню из 4
пунктов (тот же список, что `USER_SETTABLE_STATUSES`), запись оптимистичная с откатом;
почтовый цикл выключен (общий ящик матчил компании через всех юзеров).

## Последний заход

- Купол → плашка; цифра больше не налезает на концы дуги; телефон больше не складывает
  заголовок в столбик.
- Проверено рендером настоящего компонента (`demo`-проп) в встроенном Chromium: 1280 и 390,
  день и ночь, состояния «без капа», «кап + 3 платформы», «ищет, 0 отправок», «пачка 3 из 7».
  Временная превью-страница в коммит не вошла (`/preview/tap-dock` на main удалён).
- Грабля: локальный `jobflow-website` на main отстаёт от origin (~10 коммитов) и держит
  чужие незакоммиченные правки (buddy) — работать в worktree от `origin/main`.

## Сломано / не доделано

- Док на живой кампании с реальными числами ещё не смотрели (опрос раз в 8 с).
- Одна платформа → чип «Indeed 3» повторяет цифру в дуге; Игорю предложено скрыть, ответа нет.
- «Tailored resume» в History у большинства строк пуст — причина в тейлоринге
  (`jobflow/docs/handoff/pool-quality.md`), не в витрине.
